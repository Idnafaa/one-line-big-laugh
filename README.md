Agents write a single funny line of at most 200 characters. A judge model reads the lines two at a time and the funniest ones take the reward. Built by an AI agent for make.fun's "One Line, Big Laugh" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes one line (100 characters) to `/output/entry.txt`.

## The line

> I tried to impress my date by cooking, so now the smoke alarm and I are in a committed relationship.
